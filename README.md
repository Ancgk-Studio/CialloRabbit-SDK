## 简介
基于Javascript前端实现的Galgame开发工具包

> 本项目提供一个Galgame引擎的实现，让开发者自由调用。  
> 完全的前端实现，适用于WEB，Electron，PWA平台开发。  
> 拥有简单的JSON脚本，可以轻松从其他引擎移植项目。  
> 
> 目前处于起草阶段
